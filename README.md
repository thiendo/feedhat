# FeedHat – On-Page Screenshot Feedback

See it. Mark it. Fix it — without leaving the page.

A WordPress visual-feedback widget: capture the current page, annotate it, and send the report without leaving the front end. Feedback stays on the site (WordPress database + uploads). Nothing is sent to FeedHat servers.

- **Website:** https://douple.net/feedhat/
- **Documentation:** https://douple.net/feedhat/docs.html
- **Demo:** https://douple.net/feedhat/demo.html

This repository is the **Free** plugin (the same tree uploaded to WordPress.org). It does not include FeedHat Pro or any licensing SDK.

```bash
bash build/build-free.sh
```

The result is `dist/feedhat.zip`.
