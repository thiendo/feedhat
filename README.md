# FeedHat – On-Page Screenshot Feedback

See it. Mark it. Fix it — without leaving the page.

FeedHat adds a floating feedback button to your WordPress site. Visitors and clients can capture a screenshot of exactly what they're looking at, draw on it, add a written note, and send it — without leaving the page.

Every piece of feedback is stored in your own WordPress database and uploads folder. Nothing is sent to FeedHat servers or any other third party.

- **Website:** https://douple.net/feedhat/
- **Documentation:** https://douple.net/feedhat/docs.html
- **Demo:** https://douple.net/feedhat/demo.html

## Install

1. Upload the plugin to `/wp-content/plugins/feedhat`, or install it from **Plugins** in WordPress.
2. Activate FeedHat.
3. Go to **FeedHat → Settings** to choose where the button appears, its color/label, targeting, and email notifications.
